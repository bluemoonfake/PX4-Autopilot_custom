# ArduPilot Legacy Reference

This directory contains historical artifacts retained for feature comparison with ArduPilot AntennaTracker.

They are **not part of the PX4 firmware**, are not compatible PX4 parameter files, and must not be used as PX4 validation tools. Consult [the PX4 comparison reference](../../../../docs/en/antenna_tracker/reference/ardupilot_gap.md) and the canonical roadmap instead.
